| NO | UI 요소명 | 인터랙션 및 로직 정의 | 이동 화면 / 비고 | 매핑 요구사항 ID |

### 📱 [SCR-LIVE-001] 라이브 합석 동영상 플레이어 & 실시간 채팅 패널

#### 와이어프레임 (Wireframe)
```
+-----------------------------------------------------------------------------------------------+
| [HEADER] 👑 내가 방장 (or 👑 방장: 혼밥마스터)   🟢 12명 함께 합석 중   [💬 채팅 접기]   [X]    |
+----------------------------------------------------------------+------------------------------+
|                                                                | [LIVE CHAT PANEL]            |
|                                                                | 👑 방장 키워드 검색 & 영상교체|
|                 YOUTUBE EMBED VIDEO PLAYER                     | [ 입력: 성시경        ][검색] |
|              (방장과 100% 동기화된 타임스탬프)                 +------------------------------+
|                                                                | [검색결과 카드 뷰어]          |
|                                                                | 🖼️ 킬링보이스 ⏱️22:09 [▶️재생]|
|                                                                +------------------------------+
|                                                                | 💬 라이브 채팅 이력 (최근 50개) |
|                                                                |  - 방장: 식사 맛있게 하세요! |
|                                                                |  - 나: 네 ㅋㅋㅋ 꿀잼이네요 |
+----------------------------------------------------------------+------------------------------+
```

#### 디스크립션 (UI Element Description)

| NO | UI 요소명 | 인터랙션 및 로직 정의 | 이동 화면 / 비고 | 매핑 요구사항 ID |
| :---: | :--- | :--- | :--- | :--- |
| ① | `👑 영상 틀기` 버튼 | 방장에게만 노출. 클릭 시 방장 전용 키워드 검색 및 영상 교체 패널토글 | 내부 드로어 | REQ-F-005 |
| ② | `유튜브 검색` 입력창 | 키워드 입력 후 검색 클릭 시 실시간 검색 결과 카드 목록 노출 | 내부 드로어 | REQ-F-002 |
| ③ | `[▶️ 재생]` 버튼 | 클릭 시 WebSocket `HOST_CHANGE_VIDEO` 이벤트를 발생시켜 룸 전원 영상 교체 | 비디오 플레이어 | REQ-F-006 |
| ④ | `비디오 플레이어` | 입장 시 `SYNC_VIDEO_STATE` 타임스탬프로 점프하여 방장과 100% 동일 시점 감상 | 외부 <iframe> | REQ-F-006 |
| ⑤ | `실시간 채팅 영역` | 메시지 입출력 처리 및 방 진입 시 최근 50개 대화 내용(`CHAT_HISTORY`) 복원 | 내부 스크롤 | REQ-F-007 |
| ⑥ | `🟢 시청자 수` 뱃지 | PresenceManager 세션 기반 100% 실제 합석 시청자 수 실시간 갱신 표기 | 뱃지 컴포넌트 | REQ-F-008 |
